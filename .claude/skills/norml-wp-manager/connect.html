Connect WordPress without putting the key in chat.

This page runs entirely on your computer. It makes no network requests and sends nothing to Norml, Claude, or any other service.

Local-only connector · network disabled

1. Authorize the Copilot in WordPress

Open WordPress authorization

WordPress will show a separate, revocable Application Password once. Copy that value—never your normal login password.

2. Save the one-time local handoff

Choose the folder where you want this site’s reusable Copilot dossier. The connector creates {site-name}/.wpm/credential.handoff, already excluded from Git. Return to the Copilot immediately so it can validate, lock, import, and delete the handoff.
